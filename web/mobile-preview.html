VISUAL UPDATE · PROVIDER INBOX

A clearer workspace for providers

The Provider Inbox now follows the same visual hierarchy as the Owner home: a navy workspace header, separate white overview cards, and easier-to-read request cards. The colors and spacing are calmer without changing the booking workflow.

  1. Choose Service Provider on the login screen and use the pre-filled demo values.
  2. Skip onboarding to see the revised Inbox.
  3. Try New, Active, Done and All, then open a request to see its details.

Accept remains the navy primary action; Decline is clearly labelled with a restrained warning color. The request details, status chips and local demo actions are unchanged.

The app still uses local sample data and resets on refresh. A report-aligned Supabase schema and acceptance function have been drafted, but are not deployed or connected. Real accounts, cloud storage and notifications remain to be implemented.
